STDP PYTHON/SPECTRE COMMANDS
============================

Run these commands from the Full directory:

cd /home/sheng/STDP/Full


1. ACTIVATE THE PROJECT ENVIRONMENT AND INSTALL DEPENDENCIES
------------------------------------------------------------

Activate the existing project virtual environment:

source ../.venv/bin/activate

If ../.venv does not exist yet, create and activate it first:

python3 -m venv ../.venv
source ../.venv/bin/activate

python3 -m pip install -r requirements.txt

The remaining commands assume that this environment is active.


2. SHOW ALL COMMAND-LINE OPTIONS
--------------------------------

python3 main_encoding.py --help
python3 main_stdp.py --help
python3 import_data.py --help


3. GENERATE THE MNIST SPIKE/PWL DATASET
---------------------------------------

Default encoding using cached spike trains when available:

python3 main_encoding.py --seed 1 --no-plot

Regenerate a denser spike train by increasing max-spikes:

python3 main_encoding.py --duration-us 100 --dt-us 1 --max-spikes 80 --targets 0 4 7 --samples-per-class 20 --seed 1 --rebuild-spikes --no-plot

Use 0.5 us spike bins (200 bins in each 100 us sample):

python3 main_encoding.py --duration-us 100 --dt-us 0.5 --max-spikes 25 --targets 7 --samples-per-class 50 --seed 1 --rebuild-spikes --no-plot

Generate a custom PWL filename:

python3 main_encoding.py --duration-us 100 --dt-us 1 --max-spikes 80 --targets 0 4 7 --samples-per-class 20 --seed 1 --rebuild-spikes --output-pwl inputs/my_mnist.sp --no-plot

Compact an existing generated PWL file without rebuilding the dataset:

python3 main_encoding.py --compact-existing-pwl

Write the dense reference PWL representation:

python3 main_encoding.py --dense-pwl --seed 1 --no-plot

Notes:
- --max-spikes controls neural spike density. Use --rebuild-spikes after changing
  --duration-us, --dt-us, --max-spikes, or the random seed.
- --dt-us accepts fractional values such as 0.5. duration-us must be exactly
  divisible by dt-us. With the default --points-per-us 10, the minimum supported
  spike bin is 0.1 us.
- --dense-pwl only writes more waveform points. It does not create more spikes
  and normally makes Spectre slower.
- The default generated input is mnist_digit1_20samples_7.sp.


4. RUN THE STDP SPECTRE SIMULATION
---------------------------------

Recommended run using the default generated input dataset:

python3 main_stdp.py --inputs 64 --neurons 4 --timestep-us 0.2 --save-period-us 0.2 --base-gap 1e-9 --gap-sigma 0.01 --mem-threshold 0.40 --adaptive-a-min-mag 0.01 --adaptive-a-max-mag 0.50 --learning-rate-scale 0.20 --positive-dt-dg-ratio 0.40 --threads 8 --no-show

The simulation duration is automatically read from the generated PWL header.
To force a specific duration, for example 1000 us:

python3 main_stdp.py --inputs 64 --neurons 4 --timestep-us 0.2 --save-period-us 0.2 --simulation-us 1000 --base-gap 1e-9 --gap-sigma 0.01 --mem-threshold 0.40 --adaptive-a-min-mag 0.01 --adaptive-a-max-mag 0.50 --learning-rate-scale 0.20 --positive-dt-dg-ratio 0.40 --threads 8 --no-show

Use coarser 1 us output sampling for a smaller raw file while retaining the
0.2 us internal simulation step limit:

python3 main_stdp.py --inputs 64 --neurons 4 --timestep-us 0.2 --save-period-us 1 --threads 8 --no-show

Run with a custom dataset generated by main_encoding.py:

python3 main_stdp.py --input-pwl inputs/my_mnist.sp --inputs 64 --neurons 4 --threads 8 --no-show

Run with an explicit Spectre executable:

python3 main_stdp.py --spectre /path/to/spectre --threads 8 --no-show

Generate temp/stdp.sp without running Spectre:

python3 main_stdp.py --no-run

Run the simulation without generating figures:

python3 main_stdp.py --threads 8 --no-plot

Run without APS or multithreading for comparison/debugging:

python3 main_stdp.py --no-aps --threads 0 --no-show


4A. PLOT THE STDP TIMING/INITIAL-GAP DEPTH MAP
----------------------------------------------

Sweep gap time from -4000 ns to +4000 ns and initial gap from 0.9 nm to
1.1 nm. Save the equalized delta-G depth map, overlaid timing curves, and
CSV:

python3 plot_stdp_window.py --delta-min-us -4 --delta-max-us 4 --delta-step-us 0.25 --gap-min-nm 0.9 --gap-max-nm 1.1 --gap-step-nm 0.025 --plot-metric conductance --learning-rate-scale 0.20 --no-show

Reduce the positive-delta-t |delta-G| branch to 40% of the negative branch:

python3 plot_stdp_window.py --delta-min-us -4 --delta-max-us 4 --delta-step-us 0.25 --gap-min-nm 0.9 --gap-max-nm 1.1 --gap-step-nm 0.025 --plot-metric conductance --learning-rate-scale 0.20 --positive-dt-dg-ratio 0.40 --no-show

Use a finer timing sweep:

python3 plot_stdp_window.py --delta-min-us -3 --delta-max-us 3 --delta-step-us 0.1 --gap-min-nm 0.9 --gap-max-nm 1.1 --gap-step-nm 0.025 --plot-metric conductance --learning-rate-scale 0.20 --no-show

Generate the original one-gap line plot at gap_ini=1e-9 m:

python3 plot_stdp_window.py --base-gap 1e-9 --delta-min-us -5 --delta-max-us 5 --delta-step-us 0.25 --learning-rate-scale 0.20 --no-show

Match a run that used adaptive-a-max-mag=0.5 and a 1 us RRAM timestep:

python3 plot_stdp_window.py --adaptive-a-max-mag 0.5 --timestep-us 1 --no-show

Notes:
- Delta-t is t_post - t_pre at the falling threshold crossings that start the
  programming ramps. Positive delta-t means that the pre event occurs first.
- Results are written to stdp_window/stdp_window.png and
  stdp_window/stdp_window.csv by default.
- The default gap sweep is 0.9 nm to 1.1 nm in 0.025 nm steps. The PNG contains
  a delta-G color-depth map and one delta-G timing curve per gap. Use
  --plot-metric resistance when a delta-R figure is wanted instead.
- Supplying --base-gap in meters overrides the gap sweep and restores the
  original one-dimensional timing-window plot.
- This isolated sweep uses the same adaptive_spikegen.va, spikegen.va, and
  rram.va models as main_stdp.py. The learning-rate scale defaults to 0.20.
- The dynamic controller uses adaptive-r-ref=263244 ohm, SET exponent 1.61,
  RESET exponent 2.02, and curvature 0.30 to equalize delta-G over 0.9-1.1 nm.


5. GENERATE FIGURES FROM AN EXISTING RESULT
-------------------------------------------

Regenerate static PNGs and animated GIFs from temp/out.raw without rerunning
Spectre:

python3 main_stdp.py --plot-existing --no-show

Generate only the dynamic RRAM weight-map GIFs:

python3 main_stdp.py --plot-existing --animation-only --animation-frames 80 --animation-fps 10 --no-show

Generate smoother animations with more frames:

python3 main_stdp.py --plot-existing --animation-only --animation-frames 160 --animation-fps 15 --no-show

Generate static figures without animated GIFs:

python3 main_stdp.py --plot-existing --no-animate-weights --no-show

Save figures in a custom directory:

python3 main_stdp.py --plot-existing --figure-dir results/figures --no-show

Notes:
- --plot-existing reads WORKDIR/out.raw. The default work directory is temp.
- Use --workdir PATH when the raw result is stored in another work directory.
- The animated maps use uniformly spaced simulation times and a fixed
  conductance color scale across neurons and frames.


6. EXPORT THE SPECTRE RESULT TO CSV
-----------------------------------

python3 import_data.py temp/out.raw --csv temp/out.csv


7. IMPORTANT PARAMETER LIMITS AND DEFAULTS
------------------------------------------

main_stdp.py defaults:
- Inputs: 64
- Neurons: 4
- Timestep: 0.2 us
- Spectre APS: enabled
- Spectre threads: 8
- Membrane threshold: 0.40 V; valid range is 0 <= value < 0.50 V
- Adaptive ramp reference voltage: -0.422 V
- Adaptive reference resistance: 263244 ohm
- Adaptive minimum voltage magnitude: 0.01 V
- Adaptive maximum voltage magnitude: 0.50 V
- Allowed initial gap range: 0.9-1.1 nm; Gaussian samples are bounded to it
- SET/RESET equalization exponents: 1.61 / 2.02
- Equalization curvature: 0.30
- RRAM SET/RESET learning-rate scale: 0.20 (use 1.0 for the original rate)
- Animation frames: 80
- Animation playback: 10 frames/s

main_encoding.py defaults:
- Sample duration: 100 us
- Encoding step: 1 us
- Maximum spike rate parameter: 40
- Target digits: 0 4 7
- Samples per class: 20
- High/low voltage: 1.2 V / 0.0 V


8. SHELL SYNTAX REMINDER
------------------------

Every example above is intentionally a single line. If a command is split
across lines, the backslash must be the final character on the line. Do not put
a space after it.
